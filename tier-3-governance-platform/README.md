# Tier 3: The Governance Platform

*The goal of Tier 3 is to implement the bylaws and the JFA standard in the governance layer code; Slack and its workflows stand in until the official system is built.*

The platform used to govern today is Slack. polis-bridge is interim deliberation tooling.
